# 04. Advanced Mode and Embedded ComfyUI Integration

## Цель

Зафиксировать архитектуру и требования к расширенному режиму генерации (**Advanced Mode**), который станет следующим этапом развития после завершения и стабилизации **Simple Mode**.

Advanced Mode объединяет профессиональные генеративные пайплайны, прямое управление графами воркфлоу и нативную интеграцию с веб-интерфейсом ComfyUI без необходимости ручного переключения между окнами браузера.

---

## 1. Режимы генерации в Advanced Mode

В отличие от Simple Mode, ориентированного на лаконичную работу с промптами и базовыми параметрами, Advanced Mode предоставляет полный контроль над специализированными пайплайнами:

### Txt2Img (Generate)
- Классическая генерация с нуля по составленному промпту.
- Выбор чекпоинта, VAE, CLIP, настроек латента, семплера, шедулера и шагов генерации.

### Img2Img / Style Transfer (Adapt / Remix)
- Трансформация исходного медиа-ассета по текстовому описанию.
- Тонкий контроль силы шума (`denoise`), цветопередачи и композиционного сходства.
- Перенос стиля с сохранением семантики сцены.

### Inpaint / Outpaint (Локальная замена по маске)
- Интерактивный редактор масок прямо в интерфейсе приложения.
- Локальная перерисовка выбранных зон (замена одежды, фона, исправление дефектов).
- Outpainting: достраивание и расширение холста за пределы исходных границ изображения.

### Hi-Res Fix / Upscale Detailer (Enhance)
- Двухстадийный пайплайн апскейла (Latent Upscale + Model Upscale через ESRGAN / DAT / UltraSharp).
- Автоматический детект и доводка лиц и рук (Face/Hand Detailer / Adetailer).

### IP-Adapter / FaceID (Кондиционирование по референсу)
- Использование одного или нескольких референсных изображений.
- Сохранение идентичности персонажа (консистентные лица, прически, одежда) между генерациями.
- Перенос позы и композиции без жесткого текстового перегруза.

## 2. Встроенная интеграция с веб-интерфейсом ComfyUI (Embedded Editor)

Для максимального удобства пользователя приложение должно предоставлять бесшовный доступ к интерфейсу ComfyUI:

- **Встроенный Webview / Iframe:** Возможность открыть и отобразить оригинальный UI ComfyUI прямо внутри вкладки/панели Meta Viewer без необходимости вручную открывать браузер и переходить по адресу `http://127.0.0.1:8188`.
- **Автоматический handshake и привязка портов:** Приложение автоматически определяет активный порт локального или переносного (Portable) процесса ComfyUI и встраивает нужный endpoint.
- **Двусторонний обмен данными:**
  - Передача составленного промпта, выбранных моделей и параметров из Meta Viewer напрямую в граф ComfyUI.
  - Мониторинг прогресса очереди (`prompt queue`, `executing node`) с отображением статуса в UI Meta Viewer.
  - Автоматический подхват сгенерированного результата обратно в библиотеку ассетов с сохранением всей родословной (lineage) и метаданных.

---

## 3. Экспорт и интерактивная правка Workflow JSON

Пайплайн работы с графами нод должен учитывать различия окружений:

- **Экспорт Workflow JSON:**
  - Экспорт в двух форматах: *UI Graph JSON* (для визуального редактирования нод) и *API Prompt JSON* (для прямого программного исполнения).
- **Решение проблемы несовместимости компонентов:**
  - В реальных воркфлоу часто возникают расхождения в названиях кастомных нод (Custom Nodes), версиях узлов или именах файлов моделей.
- **In-Place редактирование («Подшаманивание»):**
  - При возникновении ошибок или необходимости кастомизации пользователь может в один клик открыть экспортируемый/проблемный JSON прямо во встроенном редакторе ComfyUI.
  - Пользователь вносит точечные правки в связи нод прямо на холсте, проверяет запуск и сохраняет исправленный шаблон как рабочий пресет.

---

## 4. Ограничения и принципы разработки

- **Последовательность разработки:** Разработка Advanced Mode начинается строго после того, как Simple Mode будет полностью завершен, отполирован и проверен в реальных сценариях.
- **Не эмулировать нодовый движок с нуля:** Приложение не должно заново реализовывать собственный графический canvas для нод; используется оригинальный Web UI ComfyUI через встраивание и API.
- **Разделение режимов:** Пользователь должен иметь возможность легко переключаться между простым режимом (Simple Mode) и профессиональной студией (Advanced Mode) без потери данных текущей сессии.

---

## 5. Критерии готовности

- [ ] В интерфейсе реализован переключатель режимов Simple Mode ↔ Advanced Mode.
- [ ] Поддерживаются базовые шаблоны для Txt2Img, Img2Img, Inpaint, Upscale и IP-Adapter.
- [ ] Интерфейс ComfyUI открывается и полноценно функционирует внутри Meta Viewer.
- [ ] Реализован экспорт Workflow JSON с возможностью мгновенного открытия в embedded-редакторе для доводки.
- [ ] Сгенерированные через Advanced Mode изображения корректно индексируются с полным деревом метаданных и связями.
