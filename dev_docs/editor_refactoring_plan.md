# План рефакторинга редактора воркфлоу (Workflow Editor)

## 1. Введение и цели рефакторинга

Текущая архитектура редактора воркфлоу пыталась автоматически угадывать структуры ComfyUI графов и подстраивать под них слоты моделей (например, `MODEL`, `CLIP`, `VAE`, `UNET`). Это привело к серьезным проблемам гибкости и багам:
* Модели вроде **Moody Krea 2 Mix** или кастомные архитектуры (например, `Krea-2 Text Encoder` на базе `Qwen3-VL`) используют специфичные ноды (с параметрами вроде `type: krea2`) и не имеют стандартных CLIP-выходов или привычных входов.
* Попытка интерфейса выступать «умным генератором графов» привела к перезакладыванию логики, ошибкам загрузки мета-тензоров (`Cannot copy out of meta tensor; no data!`) и визуальной перегруженности UI.
* Интерфейс из удобной оболочки превратился во второй усложненный ComfyUI, при этом потеряв согласованность: кнопки перевода и AI-помощников разбросаны, настройки сгруппированы в 3 уровня вложенности аккордеонов, а неудачные генерации «залипают» постоянными карточками на экране.

## 2. Ключевые архитектурные изменения

### 2.1 Переход от угадывания к импорту и валидации воркфлоу
1. **Основной сценарий (Advanced / Custom Workflows):**
   * Пользователь сам импортирует воркфлоу в формате `.json` (ComfyUI API Format / Exported Workflow) через отдельную удобную модалку **«Импорт воркфлоу»**.
   * После принятия JSON веб-приложение анализирует ноды графа и извлекает список затребованных ресурсов (`unet_name`, `checkpoint_name`, `clip_name`, `vae_name`, `lora_name`).
   * Приложение выполняет сверку с доступными локальными файлами моделей ComfyUI и формирует **Чеклист недостающих моделей** (*Missing Models Checklist*).
   * **Важное правило:** Приложение **не дает внешних ссылок**, не указывает, откуда скачивать и куда что вставлять. Выводится только фактологический список отсутствующих файлов — пользователь самостоятельно решает вопрос с моделями.

2. **Базовый сценарий (Built-in Base Workflows):**
   * Сохраняется набор готовых стандартных базовых воркфлоу (SD 1.5, SDXL, Flux Text2Img) для быстрой работы из коробки со стандартными чекпоинтами без необходимости импортировать JSON.

## 3. UI/UX Оптимизация редактора

### 3.1 Фикс залипающих уведомлений о неудачных генерациях
* **Текущая проблема:** Неудачные генерации (`status: 'failed'`) рендерятся в виде постоянных крупных карточек `.run-history-card.failed` прямо в ленте/истории холста (`nonOutputRuns`), из-за чего экран захламляется горизонтальными блоками ошибок (например, `Generation #48 failed`).
* **Решение:**
  * Удалить постоянный рендеринг застрявших карточек ошибок из центрального холста.
  * Уведомления об ошибках генерации сделать **всплывающими тостами (Toast Notifications)** с автоматическим скрытием или кнопкой закрытия `✕`.
  * При необходимости подробной диагностики добавляется нельззя вызываемый бейдж или раскрываемая панель логов, но не постоянный блок на холсте.

### 3.2 Упрощение левой панели (Left Sidebar)
* **Удаление лишних элементов:**
  * Полный демонтаж неиспользуемой/бесполезной функции сравнения (Compare).
  * Вынос кучи разрозненных кнопок AI и перевода (`Create with AI`, `Translate`, `Adapt`, `Reconstruct`) из левой панели.
* **Переработка структуры левой панели:**
  1. **Карточка активного воркфлоу:** Выбор базового шаблона или кнопка «Импортировать свой JSON».
  2. **Привязка моделей (Model Bindings):** Селекторы для найденных в воркфлоу слотов + статус готовности файлов (зеленый галок / предупреждение о недостающих файлах).
  3. **Базовые параметры:** Размер/Соотношение сторон (Aspect Ratio), количество изображений (Batch Count), сид.
  4. **Кнопка вызова расширенных настроек.**

### 3.3 Компактный и удобный Prompt Bar
* Интеграция компактного меню **AI Prompt Assistant** прямо в панель ввода промпта (рядом с кнопкой `✦` / тулбаром промпта).
* Все операции (`Translate`, `Enhance`, `Adapt`) вызываются в один клик из выпадающего меню промпта, не занимая место на левой панели.

### 3.4 Рефакторинг расширенных настроек (Advanced Settings)
* Избавление от глубоких каскадных аккордеонов (3 уровня вложенности).
* Перенос расширенных параметров (Sampler, Scheduler, Steps, CFG, Denoise, Seed, Filename prefix, JSON Inspector) в чистый **Drawer** (боковую выдвижную панель) или модальное окно с логической табуляцией:
  * Tab 1: **Сэмплинг и генерация** (Sampler, Steps, CFG, Denoise).
  * Tab 2: **Файлы и метаданные** (Filename prefix, Seed mode).
  * Tab 3: **Граф ComfyUI** (Инспекция и редактирование JSON).

## 4. План поэтапного внедрения

### Этап 1: Исправление уведомлений об ошибках
* Модифицировать `app/static/js/features/workflow-editor.js`: отключить добавление `nonOutputRuns` в ленту истории `run-history-card`.
* Перевести вывод `run.error` на стандартную систему тостов `showToast(msg, 'error')` с таймаутом и ручным закрытием.

### Этап 2: Бэкенд валидации воркфлоу и проверки моделей
* Обновить `app/comfyui/workflow_import.py` и `app/comfyui/workflow_models.py`:
  * Реализовать точный парсер требуемых файлов из ComfyUI API JSON.
  * Реализовать эндпоинт `/api/editor/workflows/validate-models`, возвращающий структуры `{ available: [...], missing: [...] }`.

### Этап 3: Редизайн UI Editor
* Обновить `app/templates/` и `app/static/js/features/workflow-editor.js`:
  * Вынести AI-инструменты промпта в Prompt Bar.
  * Удалить лишние кнопки перевода и сравнения из левой панели.
  * Создать усовершенствованную модалку загрузки JSON с выводом статуса отсутствующих моделей.
  * Переработать панель расширенных настроек.

### Этап 4: Верификация и тестирование
* Проверить импорт пользовательских JSON воркфлоу в браузере.
* Проверить корректность вывода предупреждений при отсутствии моделей.
* Убедиться в отсутствии «залипающих» уведомлений.
