# 05. Character and Environment Studio

## Цель

Создать специализированную студию для работы с постоянными сущностями (**Персонажи** и **Окружения**), обеспечивающую высокую консистентность (повторяемость) внешности, стиля и локаций между генерациями.

Студия объединяет текстовые паспорта описания, авто-декомпозицию через Vision LLM, управление референсными изображениями для IP-Adapter / FaceID и сквозную привязку сгенерированных ассетов через метаданные для персональных галерей и фильтрации.

---

## 1. Карточка персонажа (Character Profile)

Отдельная страница и реестр персонажей позволяют создавать и хранить детализированные профили героев:

### Текстовый паспорт внешности
- Структурированное и свободное описание анатомии, черт лица, цвета глаз, прически, телосложения, отличительных признаков (шрамы, татуировки, аксессуары) и базового стиля одежды.
- Возможность быстро переопределять временные атрибуты (поза, эмоция, сезонная одежда) без изменения основного паспорта.

### Декомпозиция через Vision LLM
- Загрузка одного или нескольких изображений персонажа.
- Вызов подключенной Vision LLM (облачной или локальной VLM через Ollama / Unsloth) для автоматического извлечения точных характеристик внешности и формирования канонического описания без галлюцинаций.

### Слоты визуальных референсов (IP-Adapter / FaceID)
- Набор ячеек для прикрепления референсных изображений:
  - **Face / Portrait:** Для нод FaceID / InstantID (фиксация геометрии и черт лица).
  - **Body / Outfit:** Для передачи пропорций тела и костюма.
  - **Artistic Style:** Для фиксации стиля прорисовки (аниме, реализм, комикс).
- Назначение весов влияния (`weight / start_at / end_at`) для каждого референса.

### Быстрый запуск и тестирование
- Возможность запустить тестовую генерацию прямо из карточки персонажа для проверки стабильности внешности.
- Кнопка отправки персонажа в основной Редактор.

---

## 2. Карточка окружения и локаций (Environment Profile)

Инструмент для фиксации конкретных локаций, интерьеров и пространств:

### Мульти-ракурсная карта пространства (Multi-Photo Mapping)
- Загрузка серии фотографий/артов одного пространства с разных углов (например: вид от входа, вид на окно, крупный план деталей комнаты).
- Vision LLM анализирует серию снимков и формирует цельное семантическое описание локации: архитектура, материалы стен и пола, освещение (рассеянный свет, закат, неон), ключевые объекты и цветовая гамма.

### Референсы окружения
- Слоты для опорных изображений локации, передаваемых в фоновые IP-Adapter или Style-Conditioning ноды воркфлоу ComfyUI.

---

## 3. Матрица композиции (Character + Environment Fusion)

В основном Редакторе появляется возможность гибкой сборки сцены из сохраненных сущностей:

```text
[ Выбор персонажа: "Ая" ] + [ Выбор локации: "Неоновая кухня" ] + [ Действие/Сюжет: "пьет кофе у окна" ]
                                      │
                                      ▼
                        PromptCompiler & Advanced Router
                                      │
       ┌──────────────────────────────┴──────────────────────────────┐
       ▼                                                             ▼
Сборка итогового промпта                                  Авто-подключение референсов
(Flux / SDXL / Pony синтаксис)                            (FaceID, Outfit, Environment IP-Adapter)
```

- `PromptCompiler` бесшовно объединяет паспорта персонажа, окружения и текущее действие пользователя в один чистый промпт без взаимных конфликтов.
- Пайплайн Advanced Mode автоматически прокидывает файлы референсов в соответствующие ноды графа ComfyUI.

---

## 4. Сквозная привязка метаданных и фильтрация

Генерация, созданная с участием персонажа или локации, навсегда сохраняет эту связь:

### Запись в метаданные генерации
- В снимок параметров и SQLite базу сохраняются идентификаторы: `character_id`, `character_name`, `environment_id`, `environment_name`.
- Фиксируются точные версии паспортов и использованные референсные изображения на момент генерации.

### Персональные галереи в студии
- На странице карточки персонажа/локации отображается вкладка **«История генераций»** — все кадры, где участвовала данная сущность.

### Фильтрация в Медиа-библиотеке (Library)
- В общей галерее появляются быстрые фильтры по персонажам и локациям (например, показать все генерации с персонажем *«Ая»* в локации *«Неоновая кухня»*).

---

## 5. Хранение данных в SQLite

Сущности хранятся независимо от пересоздания файлового кэша:

```text
characters              (id, name, tags, description, created_at, updated_at)
character_references   (id, character_id, asset_id, role, weight, is_primary)
environments           (id, name, tags, description, created_at, updated_at)
environment_references (id, environment_id, asset_id, role, weight)
entity_generation_links(job_id, result_id, character_id, environment_id)
```

Удаление исходного референсного файла из галереи не ломает карточку персонажа (используются защищенные внутренние копии или мягкие предупреждения).

## 6. Критерии готовности

- [ ] Создана отдельная страница Character & Environment Studio с переключением между Персонажами и Окружениями.
- [ ] Реализован текстовый редактор карточек персонажей и окружений.
- [ ] Интегрирован вызов Vision LLM для авто-заполнения описания по одному или нескольким загруженным фото.
- [ ] Поддерживается загрузка и назначение ролей для визуальных референсов (FaceID, Body, Style, Environment).
- [ ] В основном Редакторе доступен выбор сохраненного персонажа и окружения для составления композитного промпта.
- [ ] При генерации в метаданные вшиваются `character_id` и `environment_id`.
- [ ] На странице карточки отображается персональная галерея связанных генераций.
- [ ] В общей библиотеке (Library) работают фильтры по персонажам и локациям.
